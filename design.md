# The Atomic Age
A responsive science pamphlet inspired by mid-century posters: flat ink, oversized editorial lettering, halftone printing, orbit lines and starbursts. Cream #f4ecd9, dark teal #193f3b, vermilion #bf4934, mustard #d4aa51, sage #91a497. Fraunces bold/italic display, DM Sans body, Barlow Condensed labels; self-hosted. Max width 1240px, desktop gutters 56px, mobile 22px. Asymmetric hero, alternating full-width chapters, thin borders and squarish buttons, no glossy cards or gradients. Original SVG atom illustrations and a searched vintage laboratory illustration in the quiz.

Web only: home at pages/index.tsx, composition-only re-export; implementation in pages/atomic-page.tsx and components/atom-art.tsx. Local state only, no new API or database. Anchor navigation → particle tabs → atom builder with independent steppers and presets → electron-cloud explainer → three-question quiz with explanations/restart. Visible focus, reduced motion, responsive stacking. All orbital illustrations explicitly described as simplified diagrams, not real electron paths.
